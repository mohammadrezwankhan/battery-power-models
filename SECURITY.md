# Security Policy

## Reporting a Vulnerability

GitHub private vulnerability reporting is disabled for this repository, and no
private security contact is publicly documented.

To request a private reporting channel, [open a GitHub issue](https://github.com/mohammadrezwankhan/battery-power-models/issues/new)
titled **Security contact request** and ask the maintainer for a private
contact method. Do not include vulnerability details, affected versions,
reproduction steps, exploit code, logs, or other sensitive information in the
issue. Send details only after the maintainer provides a private channel. If
no private channel is provided, do not disclose the vulnerability publicly.

No supported-version policy or response-time commitment is published.

## Documentation snapshot and maintenance

The reporting guidance above is preserved from source commit [`0304bfec25c43f42f103ebda239749b88609a187`](https://github.com/mohammadrezwankhan/battery-power-models/blob/0304bfec25c43f42f103ebda239749b88609a187/SECURITY.md#L1-L15). No new contact address, support window or response commitment is introduced by the 2026-11-19 documentation package.

For CI/report provenance and recovery procedures, see [the release playbook](docs/maintainer/CI_CD_AND_RELEASE_PLAYBOOK.md), [the existing security tooling guide](.github/security/README.md), and [the owner recovery runbook](docs/owner/BUS_FACTOR_RECOVERY_RUNBOOK.md). Keep vulnerability details and secrets out of public issues and logs while arranging the private channel described above.
