# Security Policy

## Reporting a Vulnerability

GitHub private vulnerability reporting is disabled for this repository, and no
private security contact is publicly documented.

To request a private reporting channel, [open a GitHub issue](https://github.com/mohammadrezwankhan/battery-power-models/issues/new)
titled **Security contact request** and ask the maintainer for a private
contact method. Do not include vulnerability details, affected versions,
reproduction steps, exploit code, logs, or other sensitive information in the
issue. Send details only after the maintainer provides a private channel. If
no private channel is provided, do not disclose the vulnerability publicly.

No supported-version policy or response-time commitment is published.
