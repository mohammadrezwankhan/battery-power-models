# Security Policy

## Reporting a Vulnerability

To report a suspected vulnerability, open this repository's [GitHub Security Advisories](https://github.com/mohammadrezwankhan/battery-power-models/security/advisories) page and select **Report a vulnerability**.

If that option is unavailable, ask the maintainer for a private contact method through a [security contact request](https://github.com/mohammadrezwankhan/battery-power-models/issues/new). Keep vulnerability details, affected versions, reproduction steps, logs, and other sensitive information in the private channel.

No supported-version policy or response-time commitment is published.

## Documentation snapshot and maintenance

For CI/report provenance and recovery procedures, see [the release playbook](docs/maintainer/CI_CD_AND_RELEASE_PLAYBOOK.md), [the existing security tooling guide](.github/security/README.md), and [the owner recovery runbook](docs/owner/BUS_FACTOR_RECOVERY_RUNBOOK.md). Keep vulnerability details and secrets out of public issues and logs when reporting a suspected vulnerability.
